# 🎓 LearnFast

**LearnFast** — веб-приложение для быстрого и удобного поиска учебных материалов. Выберите тему и уровень, а сайт подберёт для вас игры, видео и интересные факты, связанные с обучением.

🔗 **Демо:** https://find-learning-resources.vercel.app/

> Слоган: *«Learn anything, faster and easier.»*

---

## ✨ Возможности

### 🔍 Поиск материалов
- Поле **«What do you want to learn?»** — введите тему, которую хотите изучить.
- Выбор **уровня сложности**: `Beginner` (начинающий), `Intermediate` (средний), `Expert` (продвинутый).
- Кнопка **Load More** — подгрузка дополнительных результатов без перезагрузки страницы.
- Разные форматы контента: **игры, видео и факты** о знаниях (раздел *DiscoverMore*).

### 👤 Профиль и персонализация
- **Регистрация / вход (Sign In)** с приветствием «Welcome, Learner!».
- Короткий **опрос при первом входе** (Question 1, 2, …) — по ответам подстраиваются рекомендации.
- Раздел **«Your Preferences»** — сохранённые предпочтения пользователя.
- **Выход из аккаунта** (Sign Out).

### 🎮 Геймификация
- **Уровни пользователя** (например, «Level 1 Learner»).
- Счётчик **открытых ссылок** (Links Opened) — прогресс растёт по мере обучения.
- Мотивационная ссылка на проект [Future Vision](https://future-vision.onrender.com/).

### 📤 Поделиться прогрессом
Окно **Share Progress** позволяет поделиться достижением:
- Facebook
- Instagram
- Snapchat
- Копирование ссылки (Copy Link)

### ⚙️ Настройки и интерфейс
- **Смена фонового оформления** (Settings → Background Theme → Change Background).
- **Три языка интерфейса:** 🇬🇧 English (EN), 🇦🇲 Հայերեն (AM), 🇷🇺 Русский (RU).
- Навигация: **Home**, **Search**, **Profile**.
- Адаптивная вёрстка (`viewport`) — сайт удобно открывать и на телефоне.

---

## 🧭 Как пользоваться

1. Откройте сайт и выберите язык интерфейса (EN / AM / RU).
2. Нажмите **Sign In**, введите имя и пройдите короткий опрос.
3. Введите тему в строку поиска и выберите уровень.
4. Открывайте найденные материалы — счётчик ссылок и ваш уровень будут расти.
5. Поделитесь прогрессом с друзьями через **Share Progress**.
